Symptom Match Studio

Coding Project · Machine Learning Demo · Deployed

Educational machine learning demo that matches selected symptoms to ranked possible outputs from a supervised model. Built to understand how symptoms become features, how a classifier learns from a CSV dataset, and why responsible disclaimers matter in health-related technology.

Machine learning is not magic — the output depends heavily on the dataset, features, model choice, and limits of the system. This project helped me understand why accuracy, uncertainty, and responsible wording matter, especially when technology touches health.

Not a diagnosis tool. Does not provide medical advice. Simplified educational demo trained on a limited dataset.
